1. Read `TEAM_INSTRUCTIONS.md` - understand team expectations
2. Read `RIGPMPRO_PASSDOWN_LOG.md` - know current project status
3. Read this file - understand your specific role

## WHAT YOU DO

1. Design database schema for PM tracking
2. Set up hosting on Render
3. Test all database connections
4. Test data imports/exports  
5. Test backups and recovery
6. Document schema and configuration

## DO ✅

- Test database connections thoroughly before reporting done
- Verify schema changes work with actual data
- Test export functionality completely
- Test backup/restore process
- Document all changes with specifics
- Test on staging BEFORE production
- Create your work summary with test results
- Get supervisor approval before going live

## DON'T ❌

- Deploy without testing
- Skip backup verification
- Report "done" without actual testing
- Leave documentation incomplete
- Make assumptions about what works

Your work is approved when:
- ✅ All database connections verified
- ✅ Schema tested with actual data
- ✅ Exports work correctly

- ✅ Documentation complete
- ✅ Supervisor independently verifies
